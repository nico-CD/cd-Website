# CD Demo Kernel

Same engineering muscle on every trade demo. Trade skins differ (offers, color, photos, labels). Behavior does not.

## Soft chrome

| Token | Value |
|-------|--------|
| Emerald | `#10b981` / hover `#0ea672` |
| Book | `https://carrillodynamics.com/book` |
| Powered by | Carrillo Dynamics → `https://carrillodynamics.com` |

Components: Prepared-for ribbon (`?biz=`), Book CTA, Powered by. Never sticky agency bars.

Owner path: `/app`. One-click “Enter owner board”. No dual-login stacks.

## Working kernel (every demo)

1. **Client conversion** — book or intake completes
2. **Owner board** — today’s jobs; status changes stick; new client action appears on the board
3. **Money strip** — updates when you act (demo numbers OK)
4. **Crew view** — simple columns/switcher (“Today · 3 techs”), no essays
5. Soft CD attribution + book CTA

**Banned:** “At Scale”, “plausible”, “not a live ERP”, multi-paragraph vision blocks. Show value in the UI.

**10-second test:** Open owner board → change a status or add a walk-in → board/money updates.

## Funnel

- **Main:** primary CTA → `/book`. Curiosity strip → hub (“Curious to see it in action? Check out our 11 demos.”)
- **Hub:** try demos → Book CTA under preview + nav/footer
- **Demos:** client site + working `/app`
